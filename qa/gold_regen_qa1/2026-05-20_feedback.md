## Report-level defects

1. **§11 daily pivots are computed from the wrong prior session.** Reverse-computing the printed
   P = $4,560.23 exactly matches (4,585.20+4,525.00+4,570.50)/3, i.e. **18-May H/L/C** — but the daily
   pivot for D = 2026-05-20 must use the last completed session strictly before D, which is **19-May**.
   Rule violated: M1_Variables `[AS_OF_DATE]`/M5 pivot-basis convention (prior day = D−1, not D−2).
   Compliant condition: recompute daily P/R1/R2/R3/S1/S2/S3 from the 19-May H/L/C. Using the level
   file directly: P=4512.0067, R1=4559.0633, R2=4636.0667, R3=4683.1233, S1=4435.0033, S2=4387.9467,
   S3=4310.9433. The printed table misses every one of these by $15.6–$164.13, all beyond the
   >0.115×ATR14 (≈$12.18) Category-3 failure threshold.

2. **§6's D−1 (19-May) close and low diverge from the leak-free level file well beyond tolerance.**
   Close: report $4,504.20 vs level file $4,482.06 → diff $22.14 (threshold for failure is
   >0.115×ATR14 ≈ $12.18). Low: report $4,486.86 vs level file $4,464.95 → diff $21.91 (threshold
   >0.20×ATR14 ≈ $21.18). Rule violated: 3.4 numbers-reconcile-against-level-file. Compliant
   condition: D−1 close must be within $12.18 of $4,482.06; D−1 low within $21.18 of $4,464.95. Every
   downstream figure keyed to this close (§1, §3, §21a/b MARKET entries) inherits the same error and
   must be regenerated once the close is corrected.

3. **§6's D−1 RSI2 does not reconcile with the level file.** Report states RSI2 = 0.0; level file
   `rsi2_full` = 24.7786 → diff 24.78, exceeding the >15-point Category-3 failure threshold. (It does
   arithmetically reproduce from the report's own — incorrect — stated closes, so this is a downstream
   consequence of defect 2, not a separate arithmetic error; fixing the OHLC series should fix this.)
   Compliant condition: RSI2 for 19-May must land within 15 points of 24.7786 once the correct closes
   are used, and the RS derivation (mean gain / mean loss over the last 2 sessions) should be shown.

## Card-level defects

9. **Trade 1 — missing the required 0.25×ATR stop buffer.** M5 rule: stop = tighter of (5-day swing
   extreme, nearest S/R) **+ 0.25×ATR14 buffer**, capped at 3.5×ATR14. The card's stop ($4,560.23) sits
   exactly on the nearest S/R pivot (daily P) with no buffer added. Using the corrected daily P from
   defect 1 ($4,512.0067) and the level file's ATR14 (105.8864), buffer = 0.25×105.8864 = $26.47, so a
   compliant stop is ≈ $4,538.48 (well inside the 3.5×ATR14 = $370.60 cap). TP1/TP2/R must be
   recomputed once the stop and the corrected D−1 close (defect 2) are fixed.

10. **Trade 1 — stop-distance cell conflates dollars and ticks.** "Distance: 56.03 ticks above entry
    (each tick = $0.01/oz, so distance = 5,603 ticks)" labels the $56.03 dollar distance as "ticks"
    before converting it. Compliant condition: state the distance in USD/oz first, then the tick-count
    conversion, without calling the dollar figure itself "ticks."

11. **Trade 1 — confluence cell is self-contradictory.** "TP1 ($4,448.17) — within $26 of monthly S1
    ($4,317) NO" states a $26 confluence claim and then negates it with "NO" in the same cell; the
    actual gap is $131.17, not $26. Compliant condition: state the true gap ($131.17) and the
    resulting confluence verdict (no confluence) without the contradictory "within $26 ... NO" phrasing.

12. **Trade 2 — labelled "TREND-DOWN variant" but does not use the M5 TREND formula.** M5 rule (TREND,
    mirrored for a down-trend short): entry = P − 0.10×(P−S1); stop = P + 0.8×(R1−P); TPs = S1 / S1.5
    (midpoint of S1,S2) / S2. The card instead enters at P exactly, stops at R1 exactly, and targets
    plain entry±1R/2R — a pivot-to-pivot construction, not the TREND-DOWN formula it claims. Using the
    corrected daily pivots from defect 1 (P=4512.0067, R1=4559.0633, S1=4435.0033, S2=4387.9467), a
    compliant card reads: entry ≈ $4,504.31, stop ≈ $4,549.65, TP1 (S1) = $4,435.00, TP1.5 =
    $4,411.48, TP2 (S2) = $4,387.95.

13. **Trade 3C — does not follow any single defined Trade-3 construction.** The card is self-labelled
    "3C: Momentum-Breakout," but M5 defines 3C as the transition variant (confirmed close beyond the
    25-day boundary by ≥0.25×ATR, stop at boundary+0.40×width, TP1=+1.0×width, TP2=1.5×width). This
    card instead borrows a 38.2%-retracement TP1 from the 3A (trend) variant and a 100%-extension SL
    rule also from 3A, while its entry logic ("1×ATR(5) below the confluence band") matches none of
    3A/3B/3C. Compliant condition: pick one fork — if the regime is TREND_DOWN, use 3A's retrace-entry
    formula in full (57.5% retrace of a logged qualifying swing, stop beyond the 0% anchor by
    0.25×ATR, TP1=38.2%, TP2=0%, TP3=100%+ extension); if the trigger is genuinely a 25-day-boundary
    close-through, use 3C in full as defined above. Do not blend rules from two forks on one card.

14. **Trade 3C — linter WARN_TP3_ORDER**, copied verbatim from `qa/gold_regen_qa1/lint_static/2026-05-20.csv`:
    TP3 ($4,440.00) sits between TP1 ($4,452.00) and TP2 ($4,407.00) rather than beyond TP2 in the
