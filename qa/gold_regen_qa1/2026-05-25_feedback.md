# Feedback — XAUUSD Gold Report, 25 May 2026 (`gold_regen_qa1`)

Numbered, specific, actionable. Numbers below are taken from `data/levels/XAUUSD_by_date/2026-05-25.csv`
(`_full` basis, `atr14_full`=98.6457, the basis this report itself claims). Nothing below speaks to
what price did on or after 25 May 2026.

## Report-level defects

1. **§11 daily pivots are built from the wrong prior session.** The table is headed "prior session
   21 May (H 4,548 / L 4,488 / C 4,535)," but the last completed session strictly before D (25 May) is
   22 May, not 21 May. A compliant daily pivot table must use 22 May's H/L/C. Using the level file's
   22 May inputs (H 4,546.04 / L 4,492.01 / C 4,506.73), the compliant levels are: P=4,514.93,
   R1=4,537.84, R2=4,568.96, R3=4,591.87, S1=4,483.81, S2=4,460.90, S3=4,429.78 (pivot tolerance is
   ±0.115×ATR14 ≈ $11.34 of these). The report's stated R1 (4,559.33), R2 (4,583.67), R3 (4,619.33) and
   S1 (4,499.33) all miss by $14.7–$27.5, each exceeding the failure tolerance. Rule violated: 1.1/3.4
   "as-of = last completed session strictly before D."

2. **§11 weekly pivots are built from the wrong week.** The table is headed "prior week 11–15 May,"
   but the last completed week before D is 18–22 May (`w_full_period`=2026-W21 in the level file). A
   compliant weekly pivot table must use that week. The level file's weekly pivots are: P=4,516.46,
   R1=4,579.28, R2=4,651.84, R3=4,714.66, S1=4,443.90, S2=4,381.08, S3=4,308.52. Every level the report
   states (P=4,656.00, R1=4,708.00 … S3=4,432.00) misses its correct counterpart by $123–$142 — more
   than 10× the $11.34 failure tolerance. This is the single largest reconciliation failure in the
   report and should be corrected first.

3. **§11 monthly pivots diverge from the level file even though both cover the same month (April
   2026).** This is not a period-selection error — it indicates the report's stated April H ($4,773.8)
   / L ($4,585) inputs do not match the executed range behind the level file. Compliant monthly levels
   (from `m_full_*`): P=4,673.69, R1=4,837.19, R2=5,052.70, R3=5,216.20, S1=4,458.18, S2=4,294.68,
   S3=4,079.17. The report's R1 (4,774.87) misses by $62.32, S1 (4,586.07) by $127.89, S2 (4,491.13) by
   $196.45, S3 (4,397.27) by $318.10 — all several multiples of the $11.34 failure tolerance, despite P
   itself landing within tolerance ($6.24 off). A compliant monthly table needs wider, better-corroborated
   April H/L inputs, not just a different month.

4. **RSI2 does not reconcile against the level file, though it does reproduce from the report's own
   closes.** The report's 22 May RSI2 = 54.5 correctly reproduces from its own five stated closes: the last two
   changes are 21May→ 4,505→4,535 (gain 30) and 22May 4,535→4,510 (loss 25); avg gain=15, avg loss=12.5,
   RS=1.2, RSI2 = 100 − 100/(1+1.2) = 54.5 — the arithmetic is not at fault. But `rsi2_full` in the level file is 0.0 for the same date, a difference
   of 54.5 points against a ≤15-point tolerance — a Category 3 failure. A compliant report must reconcile
   its close sequence against the execution feed closely enough that RSI2 lands within 15 points of 0.0
   for this date, or explicitly flag the divergence between its aggregator-sourced closes and the
   execution series.

5. **Tick-unit arithmetic is inconsistent, twice, in the same card.** Tick is defined as 0.01 USD/oz
   (§2). At that size, a $79 risk (R) is 7,900 ticks, not the "790 ticks" the Trade 1 card states; the
   $257 3×ATR runner distance is 25,700 ticks, not "2,576 ticks." A compliant card must use
   ticks = price_distance / 0.01 consistently; both figures are off by a factor of 10.

6. **Trade 1's stop rationale is self-contradictory and does not match the report's own (incorrect)
   daily pivot table.** The card cell says the stop is built from "5-day swing high $4,580 + 0.25×ATR
   buffer" and, in the same sentence, that "the tighter nearest-resistance anchor at $4,568 + buffer is
   used" — two different anchors named for one stop, neither of which arithmetically yields the stated
   $4,589. Note that $4,568 is almost exactly the level file's correct `d_full_R2` (4,568.96, see defect
   1), which does not appear anywhere in the report's own (wrong-session) §11 table — suggesting the
   §21 engine used the correct 22 May daily pivots even though §11's displayed table did not. A
   compliant card must name one anchor, apply the stated 0.25×ATR14 buffer to it explicitly (e.g.
   4,568.96 + 0.25×98.6457 = 4,593.62 on a full basis), and the displayed §11 daily table must be the
   same one the card actually used.

7. **§11 pivot-input staleness is not disclosed.** The report flags pivot inputs "SINGLE-SOURCE
   INDICATIVE" (a source-count caveat) but never discloses that the daily and weekly tables use an
   older session/week than the true D−1 session/week (see defects 1–2). A compliant report must flag
   this staleness explicitly wherever an earlier-than-available period is substituted.
