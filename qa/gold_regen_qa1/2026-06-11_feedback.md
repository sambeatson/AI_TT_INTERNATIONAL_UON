## Report-level defects

1. **D-1 (10 Jun) close is wrong on both bases, and this is the single most consequential defect.**
   §6 states the 10 Jun close as 4,110.0. The level file gives `prev_close_cash=4082.95` and
   `prev_close_full=4071.46`. Rule (brief §4): close consistent ≤0.04×ATR14, discrepancy
   0.04–0.115×ATR14, failure >0.115×ATR14. Against cash (atr14_cash=91.24), the failure threshold is
   10.49; the actual gap is 27.05 — a Category 3 failure by 2.6×. Against full (atr14_full=108.475),
   the failure threshold is 12.47; the actual gap is 38.54 — a failure by 3.1×. A compliant close must
   land within 10.49 of 4,082.95 (cash) or 12.47 of 4,071.46 (full), whichever basis the report commits
   to (see item 3). Every downstream number that uses this close (§1, §3, §4, §21b MARKET-side
   comparisons) needs to be rebuilt from the correct one.

2. **D-1 open/high/low are also outside tolerance.** Rule: consistent ≤0.09×ATR14, discrepancy
   0.09–0.20×ATR14, failure >0.20×ATR14. Cash basis: open 4,160.0 vs `prev_open_cash` 4,150.16 (Δ9.84,
   discrepancy band, ceiling 18.25); high 4,174.0 vs `prev_high_cash` 4,186.26 (Δ12.26, discrepancy);
   low 4,090.0 vs `prev_low_cash` 4,081.73 (Δ8.27, at the edge of consistent/discrepancy). Full basis:
   open Δ95.33, high Δ83.47, low Δ22.9 — all three exceed the full-basis failure threshold of 21.7. A
   compliant Wed-10-Jun row, on the cash basis, must read close to O 4,150.16 / H 4,186.26 / L 4,081.73
   / C 4,082.95.

3. **State the OHLC/pivot basis and hold it.** §2/§3 claim "Spot, loco London" / "Global 24-hour OTC
   market," which points to the `_full` columns, but the report's own stated ATR(14)≈95 (Trade 1 TP3
   field) is only 4.1% off `atr14_cash` (91.24) versus 12.4% off `atr14_full` (108.475) — i.e. the ATR
   was effectively computed cash-session while the report claims a continuous basis. Pick one basis,
   state it explicitly next to the OHLC table, and check both OHLC and ATR against the matching column
   set in the level file.

4. **Daily pivots inherit the OHLC error and fail outright.** §11's daily S1 is 4,075.3 vs
   `d_cash_S1`=4,047.70 (Δ27.6, failure threshold 10.49) and `d_full_S1`=4,006.55 (Δ68.75). Daily P is
   4,124.7 vs `d_cash_P`=4,116.98 (Δ7.72, discrepancy) and `d_full_P`=4,132.01 (Δ7.31, discrepancy). A
   compliant daily S1 on the cash basis must land within 10.49 of 4,047.70. Recompute all daily tiers
   from the corrected D-1 H/L/C (item 2) using P=(H+L+C)/3 etc.

5. **The Monthly floor-pivot table is entirely missing.** §11 has "Daily pivots" and "Weekly pivots"
   subsections only; "monthly" does not appear anywhere in the report. The output-structure spec
   requires daily, weekly, **and** monthly pivot tables, each R3→P→S3 (three levels each side). Add the
   monthly table; the level file provides `m_full_P`/`m_full_R1..R3`/`m_full_S1..S3` (and the `m_cash_*`
   equivalents) to check it against once regenerated. Also standardise the daily table (currently
   5-a-side, R5→S5) and weekly table (currently 3-a-side) to the same three-levels-each-side format.

6. **RSI2 for the as-of row does not reproduce from the report's own closes.** §6 states RSI2≈3 for
   Thu 11 Jun. Using the report's own five closes (4,259.5 / 4,192.0 / 4,160.0 / 4,110.0 / 4,118.0),
   the last two period changes are −50.0 (loss) and +8.0 (gain): mean gain 4, mean loss 25, RS=0.16,
   RSI2 = 100 − 100/(1+0.16) = 13.8, not ≈3. Per the framework this is an arithmetic-reproduction
   failure regardless of the level file. Recompute and show the working (RS and the two components) in

7. **Futures-to-spot contango is never stated with a size.** §4's "Normalized (USD/oz)" column shows
   the GC futures quote (4,293.55) rounded to 4,294 with no adjustment applied, despite §5 saying
   futures are "down-weighted." State the actual USD amount subtracted (the brief indicates the
   expected order of magnitude is roughly USD 10–25) or, if none was applied, say so and justify why the
   figure is retained unadjusted in a column labelled "Normalized."

8. **Tick size/name and the 25-session medium lookback are never declared.** `M1_Variables_v2_1.md`
