# Feedback — Gold_Report_18Jun2026.md (D = 2026-06-18)

All numbers below are from `data/levels/XAUUSD_by_date/2026-06-18.csv` (`_full` basis, matching the
report's own claimed "spot, loco London" continuous basis; `_cash` is noted where it differs).
This feedback contains no information about price behaviour on or after D.

## Report-level defects

1. **§6/§11 — the reported 17 Jun (D−1) Close and Low do not reconcile against the level file; every
   downstream pivot is therefore wrong.** Report states 17 Jun O/H/L/C = 4,331 / 4,382 / 4,274 / 4,352,
   RSI2 = 94.3. The level file gives O/H/L/C = 4,334.52 / 4,382.22 / 4,219.02 / 4,257.88, RSI2 = 23.13
   (ATR14 = 118.20). Open and High are within tolerance (diff $3.52 and $0.22). Low is off by $54.98
   (fails the >$23.64 threshold) and Close is off by $94.12 (fails the >$13.59 threshold — this is
   0.80×ATR14, not a rounding or basis issue). RSI2 is off by 71.2 points (fails the >15 threshold) and
   is directionally opposite: the report reads an overbought extension (>90) while the file's actual
   RSI2 (23.13) is close to oversold. **Rule violated**: brief §4 tolerance table / Section 7 row 3.4.
   **Compliant condition**: restate the 17 Jun Close at $4,257.88 (or $4,235.78 on a `_cash` basis, if
   the report instead intends the US-session convention) and RSI2 at 23.13, then rebuild §6's Trend/
   Validation columns and every table that inherits the close (§1, §3, §4 consensus range, §21b MARKET
   entry) from that corrected value.

2. **§11.1/§11.2/§11.3 — daily, weekly and monthly pivots all fail external reconciliation.** Using the
   report's own (incorrect) prior H/L/C the pivot arithmetic is internally correct, but every pivot
   fails against the level file except daily R2/R3, which land inside tolerance by coincidence:
   - Daily: P off $49.63, R1 off $44.27, S1 off $99.47, S2 off $104.83, S3 off $154.67 (file:
     P=4,286.37, R1=4,353.73, S1=4,190.53, S2=4,123.17, S3=4,027.33; all thresholds ~$13.6).
   - Weekly: P off $35.48, R1 off $47.05, S1 off $17.42 (file: P=4,201.48, R1=4,379.05, S1=4,039.42;
     threshold ~$13.6).
   - Monthly: P off $40.10, R1 off $196.54, S1 off $196.44 (file: P=4,559.90, R1=4,753.46, S1=4,346.44;
     threshold ~$13.6).
   **Rule violated**: brief §2 row 3.4 (external reconciliation). **Compliant condition**: recompute
   all three pivot tables from the level file's stated prior H/L/C for each timeframe (or directly from
   the file's own P/R1/S1/R2/S2/R3/S3 columns), not from the report's currently-stated OHLC.

3. **§11.1 — the daily pivot table shows 5 levels per side (R5…S5); weekly and monthly show the
   specified 3 (R3…S3).** M1's `[PIVOT_ABOVE_BELOW_DAILY]` default is 3, matching weekly/monthly, and
   no note explains the daily table's extra R4/R5/S4/S5 rows. **Rule violated**: Section 7 row 2.2 /
   M1 §E.4 default. **Compliant condition**: trim the daily table to R3→P→S3 (3 levels/side) to match
   the other two timeframes, or state explicitly why daily uses a wider chart-level count than default.

4. **§7 — all five chart sub-headings (7.1–7.5) carry no caption, placeholder, or note at all.** The
   protocol accepts a caption/placeholder in place of a dropped image but expects at least that much
   evidence. **Rule violated**: Section 7 row 2.3. **Compliant condition**: add one line per chart
   naming what it would show (e.g., "5-session OHLC candlestick — image omitted in .md conversion") so
   the section is not entirely empty.

5. **§2/§21b — no variable in the report ever states the tick size or tick name explicitly**, even
   though `[TICK_SIZE]`/`[TICK_NAME]` are required by M1 §B whenever strategy cards are produced. The
   cards consistently imply $0.01/tick (e.g. $64 = 6,400 ticks) but this is never declared. **Rule
   violated**: Section 7 row 1.1. **Compliant condition**: add a Tick size / Tick name row to §2 Market

   level is at $4,480; the confluence does not support the stated target. **Rule violated**: brief §3

   **Compliant condition**: once §6/§11 are corrected (defect 1–2), TP2 must be entry ± 2R exactly, and
   its confluence citation must name a level within a stated small tolerance (e.g. the same 0.15×ATR

   ≈$4,262. **Rule violated**: brief §3 Trade 1 stop-construction rule. **Compliant condition**: rebuild
   the stop from the corrected pivots/swing extreme with the full 0.25×ATR buffer applied.
