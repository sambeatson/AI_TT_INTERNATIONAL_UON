   `_full`): **P = 4,011.38, R1 = 4,059.56, S1 = 3,978.47, R2 = 4,092.47, S2 = 3,930.29,
   R3 = 4,140.65, S3 = 3,897.38.** The report's current daily R1/S1/R2/S2/R3/S3 (4,074.19 / 3,944.05 /
   4,149.16 / 3,888.88 / 4,204.33 / 3,813.91) all diverge from these by more than the pivot tolerance
   (0.115×ATR14 ≈ USD 13.87) and must be replaced.

4. **§6, 25-Jun RSI2 (41.6) does not reproduce from the report's own stated closes.** Rule (brief §2

   file gives `rsi2_full` = **19.84** for the same date — a 21.76-point gap from the stated 41.6, over
   the 15-point failure threshold in either direction. Recompute RSI2 from the actual close series and
   show the two changes used.
