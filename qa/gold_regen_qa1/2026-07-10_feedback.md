## Report-level defects

1. **§6/§11/§19 — 9-Jul session Low is wrong and mislabelled "verified"/"two-source corroborated."**
   §6 states the 9 July session Low as 4,022.20 and §19 certifies gold OHLC as "Two-source corroborated,
   all 5 sessions, all fields." The leak-free level file gives `prev_low_full` = 4,054.23 — a difference
   of 32.03 USD, which exceeds the 0.20×ATR14 (= 20.70 USD) Category 3 failure threshold on `atr14_full`
   = 103.4821. Notably, the report's own §4 evidence table already contains two rows close to the true
   value — Kitco's session range low of 4,053.60 and Investing.com's day-range low of 4,054.37 — but §6
   used the Forbes Advisor 24-hour rolling-window low (4,022.20) instead and certified it as verified.
   A compliant regeneration must use Low ≈ 4,054 (within the ±9.31 USD consistent band around
   `prev_low_full`), sourced to the two same-window observations already present in §4 (Kitco, Investing.com),
   and must not label a figure "two-source corroborated" when two other rows in its own table disagree
   with it by more than the stated ±0.50 USD corroboration tolerance.

2. **§6 — RSI2 does not match the leak-free reference.** The report states RSI2 = 100.00 for 9 July. It
   is internally reproducible from the report's own five stated closes (two consecutive up-closes give
   zero average loss → RSI2 = 100), so this is not an arithmetic slip — it is a direct consequence of
   defect 1's bad Low/Close pair feeding the 5-day close series. The leak-free reference is `rsi2_full`
   = 61.8799 (cash: 55.4391); the gap of 38.1 points exceeds the 15-point Category 3 failure threshold
   under either basis. A compliant regeneration must rebuild the 5-day close series from a Low near
   4,054 and re-derive RSI2 to land within 5 points of 61.88 (full) or 55.44 (cash), whichever basis it
   declares.

3. **§11 — daily floor pivots fail external reconciliation on 6 of 7 levels.** Recomputed correctly from
   the report's own (incorrect) H/L/C, but those H/L/C are themselves wrong (defect 1), so the pivot
   stack inherits the error. Against `d_full_*`: P off by 14.59 (true 4,105.36, tolerance 11.90 — FAIL),
   S1 off by 25.20 (true 4,072.62 — FAIL), R2 off by 13.46 (true 4,189.22 — FAIL), S2 off by 42.64 (true
   4,021.50 — FAIL), R3 off by 30.90 (true 4,240.34 — FAIL), S3 off by 53.25 (true 3,988.76 — FAIL). Only
   R1 (2,85 off, true 4,156.48) is within the 4.14-USD consistent band. A compliant regeneration must
   recompute P/R1/S1/R2/S2/R3/S3 from a corrected H/L/C and confirm each level is within 0.04×ATR14
   (4.14 USD) of the `d_full_*` (or `d_cash_*`, per the declared basis) values in the level file.

4. **§11 — weekly R1 also fails.** Report states weekly R1 = 4,249.77; `w_full_R1` = 4,265.8467, a
   difference of 16.08 USD against an 11.90-USD failure threshold. Weekly P (7.46 off) and S1 (0.79 off)
   are within the discrepancy/consistent bands respectively — only R1 needs correction. A compliant
   regeneration must bring weekly R1 to within 11.90 USD of 4,265.85 (or re-derive from a corrected
   weekly H/L/C so that all three reconcile together).

5. **§9/§19 — the disclosed ATR(14) estimate (92.50) understates the leak-free value by 10.6%,** which is
   material because it is used as the unit for every stop buffer and the swing-qualification test
   (defect 7). `atr14_full` = 103.4821; report ATR = 92.50, a 10.98-USD / 10.61% relative gap — just over
   the 10% "consistent" boundary and into the discrepancy band. This is correctly self-flagged as
   indicative in §19, which is good practice, but a compliant regeneration should tighten the ATR
   estimation method so it lands within 10% of 103.48, since several downstream thresholds (below) are
   sensitive to it.

## Card-level defects (Category 4 — card construction, M5 fixed rules)

6. **Trade 2 and Trade 3A stop buffers use 0.15×ATR instead of the fixed 0.25×ATR.** Both cards state
   "plus a 13.88 USD buffer equal to 0.15 × ATR(14)" (13.88 = 0.15 × 92.50). The M5 rule fixes this
   buffer at 0.25×ATR for both the Trade 2 structural stop and the Trade 3A stop beyond the 0% anchor.
   Even using the report's own (indicative) ATR of 92.50, the compliant buffer is 0.25 × 92.50 = 23.13
   USD, not 13.88. Using the leak-free `atr14_full` = 103.4821, the compliant buffer is 25.87 USD. A
   compliant regeneration must rebuild both stops with a 0.25×ATR buffer: Trade 2 stop ≈ daily R2 +
   25.87 (on the corrected R2, see defect 3); Trade 3A stop ≈ 4,205.00 + 25.87 = 4,230.87.

7. **Trade 3A entry uses a 50% fibonacci retracement, not the fixed 57.5% the M5 rule specifies.** The
   card computes entry = 4,022.20 + 0.50×(4,205.00−4,022.20) = 4,113.60. The compliant entry is
   4,022.20 + 0.575×182.80 = 4,127.31. This is a direct, checkable rule violation, not a data-accuracy
   issue — the swing endpoints used (4,205.00 / 4,022.20) are the report's own and are not in dispute
   here. A compliant regeneration must move the entry to 4,127.31 (subject to defect 1's correction to
   the swing low itself) and recompute TP1/TP2/TP3 and R from that entry.

8. **Trade 3A's swing-qualification "borderline pass" understates its own shortfall by roughly 10x.**
   §20/§21a state the swing magnitude (182.80) is only 2.20 USD / 1.2% short of the 2×ATR requirement
   (185.00), computed using the report's own 92.50 ATR estimate. Using the leak-free `atr14_full` =
   103.4821, the true requirement is 2×103.4821 = 206.96, and the true shortfall is 206.96−182.80 =
   24.16 USD, or 11.7% — not 1.2%. This materially changes the qualification call: on the leak-free ATR,
   Trade 3A is not a marginal borderline case, it fails the qualifying-swing test by a wide margin. A
   compliant regeneration must re-run the swing-qualification test against `atr14_full` (or `atr14_cash`
   if the cash basis is declared) rather than an internally-derived, self-flagged-indicative ATR, and
   either find a qualifying swing within the 10-session adaptive lookback or suppress Trade 3A.

9. **Trade 3A TP1 is mislabelled.** The card states TP1 (4,057.11) is "the 38.2% retracement of the
   entry-to-swing-low leg," a distance of 56.49 USD from entry. But 0.382 × (entry − low) = 0.382 ×
   91.40 = 34.91, not 56.49; the 56.49-USD distance actually equals 0.618 × 91.40. The label and the
   arithmetic disagree with each other, independent of any external data check. A compliant regeneration
   must either relabel this level correctly (as whatever fibonacci fraction of whichever leg it actually
   is) or recompute TP1 to genuinely sit at the 38.2% retracement of the leg it claims to measure.
