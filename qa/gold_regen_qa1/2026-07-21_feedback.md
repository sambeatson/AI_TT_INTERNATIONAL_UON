## Report-level defects

1. **ATR14 is wrong by more than the tolerance under either basis.** §21b implies ATR14 ≈ $54.67
   (from "3×ATR(14) ≈ $164"). The level file gives `atr14_full` = $92.6614 (41.0% relative miss) and
   `atr14_cash` = $74.1371 (26.3% relative miss) — both exceed the 25% relative-difference failure
   threshold. A compliant report must state ATR14 explicitly as a number in §9 (not only implied
   through a cards-section multiple) and it must land within 10% of $92.66 (full) or $74.14 (cash),
   whichever basis the report is using. This single error is the root cause of defect 4 below.

2. **Daily pivots R2/S2/R3/S3 fail the external reconciliation; P/R1/S1 are only borderline.**
   Recomputing from the file's `_full` H/L/C, the correct daily levels are P=4010.36, R1=4037.95,
   S1=3980.06, R2=4068.25, S2=3952.47, R3=4095.84, S3=3922.17. The report's table (P=4009.6,
   R1=4029.2, S1=3988.7, R2=4050.1, S2=3969.1, R3=4069.7, S3=3948.2) is internally self-consistent
   with the report's own stated H/L/C (4030.50/3990.00/4008.30) — the formula application is correct —
   but that H/L/C itself understates the true prior-session range (true H−L ≈ $57.89 vs the report's
   $40.50), so the error compounds through the (H−L)-scaled outer levels: R2 is off by $18.15, S2 by
   $16.63, R3 by $26.14, S3 by $26.03, all beyond the $10.66 failure threshold (0.115×ATR14_full). A
   compliant regeneration must source the prior-session H/L/C from data that reproduces the file's
   4040.67/3982.78 (full) or 4019.6/3998.26 (cash) values within $9, not from the currently-used H/L.

3. **Monthly pivots (June 2026) fail on 4 of the 5 shown levels.** File values: `m_full_P`=4165.51,
   `m_full_R1`=4387.95, `m_full_S1`=3785.16, `m_full_R2`=4768.30. The report shows P=4178.6 (diff

   failure threshold. A compliant monthly table must be recomputed from June H/L/C consistent with
   the above P/R1/S1/S2/R2 values (within $10.66), and should also show the full R3→S3 band (currently
   only R2→S2 is shown, 2 levels/side instead of the required 3).
   Weekly pivots, by contrast, are excellent (`w_full_P`=4026.44 vs report 4027.1, and every other
   weekly level within $2.60) — no change needed there; the weekly section can be used as the template
   for how the daily/monthly tables should reconcile.

   elsewhere in the report (defect 1) — once ATR14 is corrected, either remove the "wide stop" language
   or re-derive the stop against the correct ATR.
