## Report-level defects

1. **Self-contradictory source citation — §4 vs §6 (triggers the hallucinated-source override, Category 3 = 0).**
   §4's Price Evidence Table gives Investing.com's own quoted "Prev close" (i.e., Investing.com's stated 29 Jul
   close, referenced from its 30 Jul intraday read) as **4,076.80**. §6 attributes the 29 Jul close as
   **4,045.17**, sourced jointly to Investing.com (Source A) and TradingEconomics (Source B), marked
   "CORROBORATED." The same source's statement of the same data point (29-Jul close) differs by $31.63 between
   the two sections. Framework 3.2 treats a source whose own quoted figure is used inconsistently elsewhere as
   fabricated. Fix: pin one verified Investing.com 29-Jul close and use it in both §4 and §6, or, if "prev
   close" in §4 refers to something other than the 29-Jul session close, relabel it so it is not read as the
   same figure.

2. **Daily pivots computed from the wrong (D−2) session — §11.1.** The header reads "Daily pivots (prior
   session 28 Jul)." The report's own as-of session (§2) is 29 Jul (D−1). Reproducing the floor-pivot formula
   on the report's own 28-Jul H/L/C from §6 (H=4,107.25, L=4,041.98, C=4,028.40) gives
   P=(4,107.25+4,041.98+4,028.40)/3=**4,059.21**, exactly the printed value — confirming 28 Jul (D−2) was used
   where 29 Jul (D−1) is required, and the header discloses this openly but does not flag it as a
   non-conformance/staleness issue anywhere (5.1 gap). Note for the regeneration agent: recomputed from the
   correct D−1 session, this specific level would land close to the printed one by coincidence — the leak-free
   `d_full_P` is 4,059.60 (Δ0.39, within tolerance) — but the wrong-session label is still a genuine process
   defect, and the report's own reproduction shows the actual computation used the wrong inputs. Re-derive all
   three daily pivot tables from 29-Jul H/L/C going forward and relabel the header.

3. **D−1 Open/High/Low fail tolerance against the level file (Category 3 failure) — §6.** Against
   `data/levels/XAUUSD_by_date/2026-07-30.csv` (`_full` basis, matching the report's claimed "Spot, loco

   cash-session basis, so this does not clear the claimed-basis check.) A compliant D−1 OHLC on the `_full`
